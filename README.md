# Harness Desktop Build

Публичный репозиторий облачной сборки Harness Desktop. Исходный код приложения хранится отдельно в закрытом репозитории:

- Source: https://github.com/maximnaumov20-alt/harness-desktop
- Build: https://github.com/maximnaumov20-alt/harness-desktop-build

Здесь размещаются только инфраструктура сборки, инструкции и готовые установщики. Исходный код приложения сюда не копируется и в артефакты не включается.

## Как устроена сборка

1. Владелец запускает workflow Build Harness Desktop вручную.
2. Указывает полный 40-символьный SHA коммита из закрытого репозитория.
3. Workflow получает исходники с помощью отдельного read-only токена.
4. Токен используется только действием checkout и не передаётся скриптам сборки.
5. На Windows GitHub-hosted runner выполняются проверки и сборка Tauri.
6. В артефакт попадают только установщики .msi и .exe.

Workflow не запускается на pull_request, push или issue из публичного репозитория. Это намеренно: публичные PR не должны получать доступ к credential закрытого репозитория.

## Однократная настройка доступа

Создайте Fine-grained personal access token в GitHub с такими ограничениями:

- Resource owner: ваш аккаунт.
- Repository access: Only select repositories → harness-desktop.
- Repository permissions: Contents: Read-only.
- Другие разрешения не выдавать.
- Срок действия выбрать минимально удобный.

Добавьте токен в Settings → Secrets and variables → Actions → New repository secret этого репозитория:

- Name: HARNESS_SOURCE_READ_TOKEN
- Secret: созданный токен.

Не публикуйте токен и не вставляйте его в исходники, Issues или сообщения. При необходимости отзовите его в GitHub Settings.

## Запуск

1. Откройте вкладку Actions.
2. Выберите Build Harness Desktop.
3. Нажмите Run workflow.
4. Введите полный commit SHA из закрытого репозитория.
5. После успешного завершения скачайте артефакт harness-desktop-installers.

Для сборки из текущей основной ветки сначала убедитесь, что нужные изменения уже находятся в main закрытого репозитория.

## Ограничения

Публичные GitHub Actions для стандартных GitHub-hosted runners обычно не расходуют минуты приватного репозитория. Это не означает гарантированно неограниченную эксплуатацию: действуют правила добросовестного использования GitHub, лимиты параллельности, длительности задач и хранения артефактов.

Публикация GitHub Release пока не включена. Сначала нужно проверить сборку и безопасность процесса.
